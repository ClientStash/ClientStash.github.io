# ClientStash

Free DonutSMP clients, cracked-client listings and Fabric mods for Minecraft 1.21.x and 26.x.

Product data lives in `products.json`. After changing a listing, run:

```powershell
python scripts/generate_static_pages.py
```

The generator updates the crawlable homepage cards, the clean `/clients/<id>/` pages, and `sitemap.xml`.
